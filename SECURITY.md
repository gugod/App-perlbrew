# Security Policy

## Supported Versions

At the moment the supported versions are as follows:

| Version | Supported          |
| ------- | ------------------ |
| 1.02    | :white_check_mark: |
| 1.01    | :white_check_mark: |
| 1.00    | :white_check_mark: |
| < 1.00  | :x:                |

## Reporting a Vulnerability

Visit the "Security and quality" tab of this project on github, navigate to the "Advisory" tab (side menu).

Or visit this link: https://github.com/gugod/App-perlbrew/security/advisories

Click "Report a vulnerability" button on the repository’s "Advisories" page to submit a private report.
